# Blueprint icons

Decided by Jose on 2026-11-21 in the icon catalogue (one row per element the house editor can create or will need). "Library" means the Nubisco UI icon named here is the one to use. "Bespoke" means a new icon has to be drawn: added to `@nubisco/ui` first if it is generic (a window, a shutter, a curtain), and only kept in OpenBridge if it is specific to it.

Status: today (can be placed now), stage 2 (door and window work), proposed (not in the app yet).
